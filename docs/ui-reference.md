## 默认窗口尺寸与预览切换

参考主窗口默认大小为1100×700逻辑像素，并居中。项目默认尺寸由1180×760调整为1100×700逻辑像素，小屏仍按工作区限制；手动调整过的尺寸继续记忆。此次启动用 `--reset-window-bounds` 清除尺寸/最大化记忆一次，之后正常保存用户窗口大小。

按用户要求，每次修正验证和打包成功后自动正常退出旧版并打开新版。新版支持 `--quit-for-update` 发送给已有实例：跳过常规退出询问，但仍保存设置、等待Backend.stop完成，再退出；失败时保留旧实例。该参数不是强杀。旧版尚无此参数时从应用菜单正常退出。

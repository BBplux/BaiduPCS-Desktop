# 已确认的产品范围

2026-11-03：用户确认进入实施。

- Windows 10/11 x64，无广告，无行为统计，不默认开机启动。
- 界面参考最新版百度网盘，重新实现保留部分的布局、样式和操作；不分发官方程序代码。
- Electron + Vue 3 + TypeScript + Vue Router + Pinia + Ant Design Vue。只采用必要的通用依赖，优先实施时最新稳定且互相兼容的版本，锁定 lockfile。
- Rust 后端独立进程，首选 BaiduPCS-Rust；先验证登录、上传下载和进程重启恢复。BaiduPCS-Go 是备选。
- 官方网页登录（账号密码由百度页面处理，成功后获取 Cookie）、扫码登录、手动 Cookie。用户在实施中明确同意上游按原方式明文保存 Cookie，不再要求 Cookie 加密。退出账号清除网页会话及凭据。
- 文件浏览、搜索、新建目录、重命名、移动、确认后删除。需验证删除确实进入回收站，不实现永久删除。
- 上传、下载、暂停、恢复、重试、任务持久化。可设下载目录；同名默认保留两份，提供跳过/覆盖下载选项。
- 关闭窗口默认驻留托盘并继续任务，可配置；主动退出提示未完成任务，保存任务并停止后端。下次恢复列表，是否自动继续可设置。
- 悬浮窗可关闭，显示上传/下载速度，支持拖动和位置记忆、打开传输列表、拖入文件上传。
- 删除会员营销、活动广告、AI、推荐、商城、好友等入口，保留文件、传输、账号容量和设置。
- 分享链接、在线播放、同步备份、多账号切换不纳入首版。

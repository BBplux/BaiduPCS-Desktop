## 保留的差异与尚未确认的状态

- 用户要求灰色禁用按钮文字更深：保留#8793a5，不改成官方很浅的#ccd4df。主按钮禁用背景按官方#a8d0ff。
- 传输行继续采用此前按用户真实任务截图确认的64px行高。5816/5790局部cell为56px加margin4px，不足以证明整行布局高度；不据局部规则回退已确认结果。
- 登录由本项目官方网页登录流程承载；扫码/Cookie补充入口和第三方说明继续保持，未把官方内部登录组件移植进来。默认头像、扫码入口、关于正文图标等尚未确认对应官方资源，保持现有库图标。
- 设置只提供已接入功能，不补无效的官方并发、会员、推广选项；同名冲突下拉框和第三方关于正文保留本项目结构。启动项复选框仍用现有可访问控件，未宣称所有勾选状态都与官方相同。
- 悬浮窗保留同时显示上传/下载速度的本项目逻辑，仍使用适合168×48px透明窗口的4px外边距阴影；未直接套用会被窗口裁切的官方16px阴影。官方会员胶囊、推广态、全部动效没有纳入。
- 本轮没有新拍官方原生窗口，也未验证设置窗口真实鼠标拖动；仅检查其拖动区域CSS及独立窗口导航/关闭。125%下的本地渲染不等于全部DPI和状态的像素验收。
